# Лабораторная работа 1: Предобработка данных

## Описание набора данных
Набор данных `insurance.csv` содержит информацию о медицинском страховании.

### Состав показателей и типы данных:
| Показатель | Тип данных | Описание |
|------------|------------|----------|
| age | int | Возраст |
| sex | object | Пол (male/female) |
| bmi | float | Индекс массы тела |
| children | int | Количество детей |
| smoker | object | Курит ли (yes/no) |
| region | object | Регион |
| charges | float | Страховые выплаты |

## Подключаемые библиотеки
- `pandas` — для работы с таблицами
- `numpy` — для математических операций
- `matplotlib` — для визуализации
- `seaborn` — для статистической визуализации

## Используемые методы предобработки
1. `pd.read_csv()` — загрузка данных
2. `df.head()` — просмотр первых строк
3. `df.dtypes` — проверка типов данных
4. `df.isnull().sum()` — проверка пропусков
5. `df.astype()` — преобразование типов
6. `df.describe()` — описательная статистика
7. `sns.histplot()` — построение гистограмм
8. `sns.boxplot()` — построение ящиков с усами
9. `sns.heatmap()` — построение тепловой карты корреляций

## Результаты
В блокноте `analysis.ipynb` выполнены:
- загрузка и просмотр данных;
- проверка типов и пропусков;
- описательная статистика;
- визуализации распределений и зависимостей.
